# LACT 无标签图独立结构审计

## 构图与对照

仅用固定 P1 checkpoint 为 7,562 条无标签 TRAIN 句子编码并建立余弦**互 8-NN** 图。边索引是离散静态整数，不反传；K=8 沿用原设计，不据结果调整。方向、`Q` 投影和真实非线性头响应在既有 `reference_400` 表示/头上测量，`Q` 只由 400 个 TRAIN 拟合标签确定。随机图保持 8,984 条边的起点与边数，打乱终点，作为同样计算量的对照。没有使用无标签 VAD 数值，也没有访问 DEV/TEST。

## 图和局部性

| 指标 | 真实互近邻图 | 随机图 |
|---|---:|---:|
| 边数 | 8,984 | 8,984 |
| 孤立点 | 1,797 / 7,562 = **23.76%** | 不适用 |
| P1 余弦距离中位数 | **.02473** | .07279 |
| P1 余弦距离 p90 | .03910 | .11234 |
| 参考模型欧氏边长中位数 | **3.618** | 5.631 |

真实边明显更短，但 P1 距离的真实 p90 与随机 p10（.03976）几乎相接，说明局部性是分布性而非绝对分界。最小余弦距离约 `−2.4×10⁻⁷` 来自浮点舍入，不能解释为真实负距离；参考表示中有重复/重合边，分母使用 `10⁻⁸` 防止除零。图的 23.76% 孤立点不会贡献任何边损失，是覆盖率限制。

## 方向分布与标签投影

令 `d=z_v−z_u`、`r=(I−QQᵀ)d`、`s=r/sqrt(||d||²+ε)`，方向二阶矩 `C_E=mean(ssᵀ)`。真实边在 `Q` 外保留 **91.88%** 的长度平方能量；随机边为 **86.81%**。真实 `C_E` 的有效秩 `(tr C_E)²/||C_E||²_F` 为 **147.94**，随机为 **37.89**，远低于 `Q` 外最多 765 维。以同 trace 的 `Q` 外各向同性矩阵为对照，真实方向二阶矩的相对 Frobenius 距离由有效秩推出约 **0.898**；它并非各向同性。真实/随机二阶矩相对 Frobenius 差为 **1.369**。

真实头的平均归一化 JVP 平方：投影后 **6.840×10⁻⁵**，未投影 **2.176×10⁻⁴**，保留约 **31.4%**；投影后按 V/A/D 分别为 **1.731/2.937/2.171×10⁻⁵**。随机边投影后为 **1.167×10⁻⁴**。`Q` 投影确实改变了头响应，且局部边与随机边的响应不同；它并不证明被压制方向对真实 VAD 无关。

在固定 32 边的 GPU 梯度检查中，真实图损失 **9.278×10⁻⁵**，随机图 **1.363×10⁻⁴**；两者头梯度余弦 **.531**、encoder 梯度余弦 **.628**，完整梯度相对距离 **1.073**。这些数值支持**图提供了不同于随机边的方向加权**，但不等于泛化收益。

## 与普通标签锚定头正则的关系

若把头 Jacobian 近似为局部常数，`L_U≈tr(J_hᵀJ_h C_E)`；若 `C_E≈α(I−QQᵀ)`，它就近似普通的 `Q` 外 Jacobian Frobenius 正则。当前方向有效秩 147.94、相对各向同性距离约 .898，故**方向分布并未退化成该各向同性正则**。真实/随机图梯度也不相同。然而，`J_h(z_u)` 随锚点变化，二阶矩差异不能单独证明参数更新与任意监督头正则都不同；需要精确的同锚点等尺度正则梯度对照才能排除近似等价。当前审查最多支持“有独立输入分布结构”，不能声称“已证实额外信息改善 VAD”。
