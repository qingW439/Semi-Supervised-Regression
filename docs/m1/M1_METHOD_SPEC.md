# M1 方法规格：全非正效用时的零门控候选

状态：**仅提出一个候选；尚未实现、尚未训练、尚未证明有效或新颖。** 本规格依附现有 HPL + `dimensional_utility.py`，不设计新的训练框架。固定协议是 EmoBank 有标注 TRAIN 500、无标签 TRAIN 7562、DEV 1000，V/A/D 三维连续回归；TEST 禁止访问。DEV 只可在预先固定机制与超参数后报告评价，不能据 DEV 调机制。

## 解决的具体问题

早期 diagonal/crossdim 160 步运行的 32 次效用探测，经 0.9 EMA 后三个维度分数始终全负。现有 `UtilityController.weights()` 把 `max(score,0)` 全零的情形回退成 `[1,1,1]`，导致已经观测到“无正向 TRAIN meta 效用”时，主训练仍使用所有无标签项，与原 HPL 完全重合。候选只处理这个**全非正分支的语义**。

## 数学假设

令 `g_k = ∇_h U_k`，`m_j = ∇_h L^{TRAIN-meta}_j`，其中 `h` 为现有回归头，`U_k` 为现有 HPL 异方差加权第 `k` 维无标签项，`j,k∈{V,A,D}`。当前的 `N_{k,j}=〈g_k,m_j〉/(||g_k||||m_j||)`（任一范数为零则置零）近似衡量沿 `-g_k` 虚拟方向对 TRAIN meta 第 `j` 维 MSE 的一阶影响。**假设 A：**平滑后所有分数不正时，继续给全部无标签维正权重的风险高于暂时不使用无标签主损失。这个假设仅针对主更新，且可能失败：head 梯度代理、有限 meta batch 和 Adam/encoder 响应可能不一致。

该假设不声称零门控可保证 DEV 改善，也不把“效用非正”解释为真实伪标签错误率。已有 HPL 的样本级异方差权重可能仍给出有效信息。

## 输入、输出与唯一改变

输入仍是当前实现从固定有标注 TRAIN meta batch 和无标签 TRAIN batch 得到的 `3×3` 余弦矩阵 `N_t`，以及现有 EMA 状态 `S_t`、模式 `diagonal/crossdim`。当前行是无标签维、列是 meta 维；diagonal 的 `score_k=(S_t)_{k,k}`，crossdim 的 `score_k=mean_j(S_t)_{k,j}`。首探测前仍用 `[1,1,1]`。输出仍是三个非负、无梯度的主训练伪标签乘子。

**唯一修改：**保留所有现有分数、EMA、截断、归一化与正分数映射，仅把 `sum_k max(score_k,0)=0` 时的输出从 `[1,1,1]` 改为 `[0,0,0]`。形式上：

```text
q_k = max(score_k, 0)
if no probe yet:                  w = (1,1,1)       # 原行为
elif sum(q) > 0:                  w_k = 3 q_k/sum(q) # 原行为
else:                             w = (0,0,0)       # 唯一变化
```

在最后分支，主训练 `L = L_supervised + λ_u·mean_k(w_k U_k)` 退化为监督损失；现有 HPL 不确定网络、其双层 meta 更新、数据取样、优化器、head/encoder、学习率、梯度裁剪、DEV 评价及保存逻辑都按当前代码保持。正分数出现时无需额外阈值或温度，沿用现有总和为 3 的权重。零向量需被视为允许的正常输出，不能被现有“权重和必须正”的断言拒绝；这是该**同一分支改动**的必要接口条件，不构成第二个机制。这里仅给规格，不改训练框架。

## 预期有效原因与实质区别

早期失效不是没有探测到矩阵，而是负效用被回退规则抹掉。改成零门控能让“全部非正”真正影响主模型梯度：在已记录的 160 步旧轨迹中，32 次探测对应区间理论上不再与 HPL 主更新完全相同，因而构成可证伪的机制差异；不推断最终性能必然提高。

与 HPL 的区别：HPL 通过可学习的每样本 log variance、TRAIN 有标注外层损失来调伪标签贡献；这里不学习新的不确定网络或伪标签，仅对现有维度效用控制器的**全非正输出分支**作确定性门控。

与此前 diagonal/crossdim 的区别：两者从对角或跨维均值得分，但全非正时都返回 `[1,1,1]`；候选在同样的输入、相同分数模式下返回 `[0,0,0]`。其余有正分数的情形完全一致。与现有 14:20 的 `[3,0,0]` 情形也完全一致。

与已发表工作的区别应谨慎表述：[HPL](https://papers.neurips.cc/paper_files/paper/2025/file/30a129d6b8e4229d1ed6d90a65ee1a76-Paper-Conference.pdf) 已覆盖双层、异方差伪标签权重；[Meta-Gradient SSL](https://proceedings.mlr.press/v130/xiao21a.html) 已覆盖有标注反馈的嵌套伪标签优化；[PCGrad](https://papers.neurips.cc/paper_files/paper/2020/hash/3fe78a8acf5fda99de95303940a2420c-Abstract.html) 已覆盖冲突梯度处理；[UMPL](https://papers.nips.cc/paper_files/paper/2025/hash/6fc46679a7ba2ec82183cf01b80e5133-Abstract-Conference.html) 已覆盖回归伪标签的不确定性反馈；[MASSTER](https://imec-publications.be/entities/publication/3ccbff9b-428b-4303-ae6a-9bb47213f39e) 已针对多目标回归的样本–目标对选择。候选的可核实差别只是在**本代码的现有回退分支**对全非正维度效用弃权；全局零门控、meta 加权和梯度门控思想本身均不能据现有检索认定新颖。若论文贡献需要新颖性证明，当前证据不足，不应声称“提出创新方法”。

## 可能失败的条件

1. `N` 是 head-only 的梯度余弦；主优化器是 Adam，encoder 同时更新，局部 head SGD 方向与真实整步结果可能不一致。
2. 16 条 TRAIN meta batch 的方向方差可能大；0.9 EMA 可能延迟从负到正的转换，零门控会错失有益无标签信号。
3. 三维权重全零时 HPL 主损失暂时缺失，可能退化为 A0 类训练；已有不确定网络的 meta 更新仍会运行，可能使状态与主损失暂时不匹配。
4. 当前弱/强视图仅是同文本 dropout，效用可能反映随机扰动而非真实标签质量；一个固定 batch 的正负符号不能推断总体效用。
5. 若真实机制目标是“始终保留 HPL 正则化”而非抑制负效用，则零门控不符合该目标。必须先固定评价准则，不能按 DEV 结果临时改回退规则。

## 最小消融实验（以后执行；本次停止）

在同一隔离实现、同一 P1 checkpoint、固定 TRAIN 500/7562、seed 0、160 步、同一 batch 顺序与所有 HPL 超参数下，预先锁定三组：A 为原 HPL；B 为现有 normalized diagonal 与 crossdim 各自的旧“全非正→均匀”回退；C 为与 B 分别配对、只改“全非正→全零”回退。B/C 配对比较是唯一机制检验，A 只提供参照。若资源只够最小一对，优先 diagonal 的 B/C，crossdim 作为同机制复核。不得更改 TRAIN 内采样或依据 DEV 调阈值；候选无阈值。

先做无需完整训练的单元验收：全负、全零、正负混合、两个不同正值四类合成矩阵；检查回退输出、`[1.757,1.243,0]` 等非均匀权重、无标签损失的实际梯度为零或非零、全 1 时与 HPL 数值一致。再检查固定 TRAIN batch 的效用矩阵和控制器记录，保留 raw/FO/cosine、分数、fallback 次数与每维主梯度范数。完整训练需另行决定；本次**不自动执行**。

评价预先只报告 DEV Macro-MAE 及各维 MAE/CCC、step 0/末步/既有规则下的最佳步，同时报告 TRAIN 内全零占比、正负分数占比与监督/无标签梯度。DEV 仅用于固定后的效果评价，不用于设计门控。预期诊断若 B 与 C 的主梯度在全非正步完全相同，则说明实现未接入；若梯度不同但 DEV 无改善，应如实判定候选无获益。TEST 始终禁止访问。
