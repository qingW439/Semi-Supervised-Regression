## 2. 组件二判定（对照 = 同折 JACF）

| 判据 | 阈值 | `acldp_ridge` 逐种子 Δ | `acldp_m0` 逐种子 Δ | 结论 |

| ΔCCC | ≥ +0.005 | **+0.0191 / +0.0235 / +0.0167** | +0.0193 / +0.0166 / +0.0113 | 两者均通过，ridge 更强 |
| ΔMAE | ≤ +0.002 | **−0.00415 / −0.00396 / −0.00245** | −0.0007 / +0.0011 / +0.0004 | 两者均通过，仅 ridge 真正改善 |
| ΔR² | ≥ −0.010 | **+0.0304 / +0.0376 / +0.0228** | +0.0027 / −0.0061 / −0.0003 | 两者均通过，ridge 明显更好 |
| 负控制 | shuffle CCC 显著更低 | 0.3455 vs 0.4459（seed0） | 未做 | 通过：收益来自差异信息而非扩大离散度 |
| 配对 CI（MAE，vs JACF） | 下界 > 0 | 三个种子全部为负且 CI 不含 0 | 两个种子 CI 含 0 | 仅 ridge 通过 |

**结论：ACLDP 在 OOF 协议下成立，且"参照模型"是方法定义的关键变量。**
- 以 **Ridge 为差异参照**：CCC +0.019 ~ +0.024、MAE 同时改善 0.0025~0.0042、R² +0.023~+0.038，
  三种子方向一致，负控制崩溃 → **组件二 GO**。
- 以旧 MLP 为参照：只有 CCC 改善（+0.011~+0.019），MAE 无改善甚至略差、R² 部分种子为负
  → 与旧 dev 结论（CCC 升、MAE/R² 退）一致，**不能作为组件二**。

这与导师的判断一致：**参照模型不能混用，旧 ACLDP 结果不可继承。**

## 4. 必须报告的保留意见

1. **E0\* 尚未冻结。** 640 步监督 MLP 的 OOF 已完成 12/15 折，逐折 MAE 约 0.155~0.191
   （均值约 0.179），**很可能优于 ridge 的 0.1846**。若 E0\* 最终是它，
   则当前 M1（0.1833）在 MAE 上会**输给 E0\***，GO-B 也不再成立。
2. 因此**下一步必须把 M1 建在同一强基座上**（先训 640 步监督，再加 JACF + ACLDP），
   而不是把"弱基座上的 M1"与"强基座 E0\*"比较。
3. Student Final 的改善幅度更大（MAE 0.1806、CCC 0.4090、R² 0.2289），
   但按预注册**不得**用它声称训练端 M1 超过 E0\*。
4. D 维首次转正（ACLDP-ridge +0.0266），但 ridge 自身 D=+0.0364 更高，说明 D 维仍主要靠线性读出。
