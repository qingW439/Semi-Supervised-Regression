## 0. 背景与动机

Phase-1 诊断（`docs/PHASE1_DIAGNOSIS_20261103.md`、`PHASE1_APPENDIX_A.md`）发现：

1. 原准入线（MAE≤0.1710、CCC≥0.4450、R²≥0.2174）是相对**欠训练的神经基座**标定的；
   一个纯监督闭式 ridge 在 dev 上三种子均值就已满足全部三项。
2. 原准入线在 JACF 预测空间内**仿射不可行**，瓶颈是宏平均 Pearson（需 ≈0.49）。
3. 因此「M1 是否成立」不能再用绝对阈值判定，必须改成**相对最强监督参照 E0\\* 的增量**。

## 1. M0 的历史定位与保留

- M0 **不再等同于某个 MLP**。M0 记为一个**监督基线集合**：`RoBERTa+MLP(L1,160步)`、
  `RoBERTa+闭式ridge`、`充分训练 MLP`、以及后续补充的监督方法。
- 旧 M0（`alpha_sweep/sup_s*`，MAE 0.17580）与其 checkpoint **永久保留**，作为历史参照，
  不得删除、不得覆盖。
- `E0*` 是从该集合中按 §3 规则选出的**最强监督参照**，用于 M1 的最终增量判定。

## 2. 审计协议（所有监督候选共用）

| 项 | 规定 |
|---|---|
| 标注预算 | lb=500，**只用该 seed 自己的 500 条** |
| 种子 | 0、1、2（各自独立划分与独立初始化） |
| 划分 | 固定 5 折 OOF manifest：`outputs/p0/fold_manifest.json`(s0)、`outputs/p0_s1`(s1)、`outputs/p0_s2`(s2)；每折 400 训练 / 100 折外 |
| 折外评价 | 每折只在自己 100 条折外样本上预测，合并成 500 条 OOF；**OOF 指标是选型依据** |
| Dev | 1000 条，仅作**报告**与最终确认，**不参与任何选择** |
| 特征 | 冻结 `pretrained/roberta-base`，mean-pool；主分析 L2 归一化（与 `encode()`/kNN 锚点一致），敏感性分析用未归一化 |
| 标签 | 与现有 `.parquet` 的 `V_norm/A_norm/D_norm` 完全一致；指标统一按 1–5 原尺度换算（×4） |
| Ridge 超参 | α 只在该折 400 训练样本内部 5 折 CV 选择；**标准化（均值/方差）只在训练折上拟合** |
| 神经超参 | 与 Ridge 同等的选择预算：候选配方数 ≤ 4，选择依据同样为 OOF MAE |
| 指标口径 | 项目既有 `metric_report`：逐维 MAE/RMSE/Pearson/SRCC/CCC/R²，宏平均 |
| 统计 | 三种子每个都报告；配对 Bootstrap（按 OOF 样本重采样，B=10000）给差值 95% CI |

**注意：五折 OOF 不等于五个随机种子**；OOF 的 500 条样本共享同一 seed 的划分与训练数据，
因此 CI 按"种子为独立单位 + 样本内配对重采样"两层报告，不把 OOF 折当独立重复。

## 3. E0\\* 的选择规则（预注册）

1. 候选集：`{MLP-L1-160步, MLP-L1-640步-bs64, MLP-L1-1600步-bs64, Ridge}`（后续新增须先注册）。
2. 选择依据：**三种子 OOF Macro-MAE 的均值**最小者。
3. 平局判定：若 OOF MAE 差值 < 0.0005，则依次比较 OOF CCC（高者）、OOF R²（高者）。
4. 约束：任何候选若出现某一维 OOF R² < −0.10（严重退化），取消资格。
5. 冻结：E0\\* 一旦按上述规则确定，即写入总账，M1 的比较目标随之固定。

## 4. M1 判定标准（预注册）

记 E0\\* 的三种子 OOF 均值为 (MAE\*, CCC\*, R²\*)，M1 为 (MAE, CCC, R²)。

**非劣界值（预先固定，不得按结果回调）**

- `δ_MAE = 0.0020`（≈1.1× 已观测监督基线三种子最大 SD 0.00175，相对 1.2%）
- `δ_R2  = 0.0100`（≈0.5× 已观测监督基线 R² 三种子 SD 0.0185，取保守值）
- `Δ_CCC = 0.0050`（必须达到的最小 CCC 增益）

| 等级 | 判据 | 结论 |
|---|---|---|
| **GO-A（强 GO）** | MAE < MAE\\* 且 CCC ≥ CCC\\* 且 R² ≥ R²\\*，三种子方向一致，配对 CI 支持 | 完整性能改善 |
| **GO-B（有条件 GO）** | MAE ≤ MAE\\*+δ_MAE 且 CCC ≥ CCC\\*+Δ_CCC（配对 CI 下界 > 0）且 R² ≥ R²\\*−δ_R2，且逐维无严重退化 | 多目标改善 |
| **NO-GO** | 只有单一指标改善，或 MAE 恶化超 δ_MAE，或种子间方向不一致 | 不成立 |

**附加硬性要求（任一不满足即 NO-GO，不降级为 GO-B）**

1. 必须报告 **Student Raw**（训练端机制）与 **Student Final**（含既定的推理后处理）两套结果；
   不得用 Student Final 的改善声称训练端 M1 超过 E0\\*。
2. 必须报告**匹配纯监督 Control**（同架构、同初始化、同训练预算、λ_u=0）与 M1 的差；
   该差用于证明"增益来自无标签数据"，不能由 M1 vs E0\\* 替代。
3. 必须报告负控制（信息源被打乱的版本）。
4. 逐维（V/A/D）指标全部报告；任一维出现 RSS 级别退化需单独说明。

## 5. 组件级判定（JACF、ACLDP 分别审计）

| 组件 | 对照 | 判据 |
|---|---|---|
| JACF | 匹配纯监督 Control（λ_u=0，其余同配置） | OOF MAE 改善且配对 CI 下界 > 0；同时报告 CCC/R² 代价 |
| ACLDP | JACF | CCC 改善 Δ_CCC 以上且配对 CI 下界 > 0，MAE 不劣于 JACF+δ_MAE，R² 不劣于 JACF−δ_R2 |
| ACLDP 参照模型 | **必须与 E0\\* 分开指定** | 若最终 E0\\*=Ridge，则 ACLDP 用 Ridge 差异与用 MLP 差异是**两个不同方法**，必须分别训练与报告，不得继承旧结果 |
| 完整 M1 | E0\\* 与匹配 Control（两者都要） | §4 |

## 6. SD Ratio 的判读规则

`γ = SD_pred/SD_true` **不追求接近 1**。由恒等式 `ρ = r·γ` 与 `CCC = 2ρ/(1+γ²)`、
`R² = 2ρ − γ²`，γ 只有在 ρ 同步提升时才有意义。因此：

- γ 上升必须伴随 OOF Pearson 或 R² 不下降，否则判为"仅放大方差"（任务书明令失败）；
- γ 的变化必须逐维报告，并与真实标签分布的逐维 SD 对照。
