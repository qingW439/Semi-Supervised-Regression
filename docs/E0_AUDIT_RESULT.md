## 3. 结论

1. **JACF 的无标签收益在严格 OOF 下成立**：相对匹配监督对照，MAE 平均 −0.0139，
   三个 seed 的配对 CI 全部为负。这是创新点一在组件层面的正面证据（此前只有 dev 证据）。
2. **Ridge 仍然优于 JACF，但优势大幅缩小**：OOF MAE 差 −0.0023（dev 上曾显示 −0.0057），
   CCC +0.0086、R² +0.0231。三项上 ridge 都更好。
3. **因此 E0\\* 暂定为 ridge（OOF 口径）**，但按预注册第 3 节，**长训练 MLP 的 OOF 尚未完成**，
   E0\\* 只能算"临时参照"，不得写成最终结论。
4. 先前基于 P1-encoder 特征的 OOF（MAE 0.0975 / R² 0.74）已作废（编码器被 500 条标注微调过，
   折外样本对编码器而言不陌生），见 `E0_AUDIT_CONTAMINATION_NOTE.md`。
5. dev 与 OOF 的绝对水平差异很大（ridge：dev MAE 0.1685 vs OOF 0.1846；JACF：0.1705 vs 0.1868），
   原因是 OOF 每折只有 400 条且评价样本不同。**今后一律以 OOF 作为选择口径，dev 只作报告。**
