# Precommitted SimRegMatch-3D EmoBank protocol

Five arms: E0 `supervised_only`; E1 `consistency_only`; E2 `calibration_only`; E3 `filtering_only`; E4 `simregmatch_full`. E0-E4 use the same P1 seed-0 checkpoint, TRAIN IDs (500 labeled, 7562 unlabeled), supervised minibatch order, optimizer, 160 steps and DEV evaluation at steps 0, 32, 64, 96, 128, 160. No TEST read. Unlabeled dropout RNG is forked per step and restored, so supervised dropout draws are unaffected by additional forwards. All data splits and initial checkpoints are hashed.

Model: RoBERTa-base, masked mean pooling, 3-value regression head, dropout 0.1, max length 128. Labeled batch 16; unlabeled batch 64; DEV batch 32. P2-comparable supervised mean L1 loss on [0,1] targets, AdamW learning rate 5e-6, weight decay 0.01, gradient clipping 1.0. Unlabeled retained-sample loss is the sum of V/A/D squared errors, averaged over selected samples, times lambda 0.01. Five MC dropout passes, beta 0.6, similarity temperature 1.0. Initial uncertainty threshold 10.0; each batch uses the preceding threshold, then sets the next threshold at the **95th percentile** of current sample uncertainty. E1/E2 accept all samples; E3/E4 filter. No extra text augmentation. Pseudo targets are detached and clipped to [0,1]. Model predictions for metrics are not clipped.

DEV metrics are on original [1,5] VAD scale: macro and per-dimension MAE, RMSE, Pearson, CCC. Lowest DEV macro MAE, including step 0, chooses best. Exact comparison with E0 is the primary gate. Preliminary GO requires E4 best macro MAE < E0, best E4 step > 0, E4 better than both E2 and E3, effective unlabeled gradient nonzero, and all integrity checks passing. Otherwise NO-GO. Only preliminary GO permits fixed-protocol seed1/2 replication; seed0 alone establishes no stable effect. The 95th-percentile correction and all settings are fixed before DEV results.

Each run uses a new, nonexisting output directory with `run_config.json`, `training_history.csv`, `dev_metrics_history.json`, `dev_metrics_best.json`, `model_best.pth`, `model_last.pth`, and `summary.json`. Config records seed, Git commit, TRAIN/DEV split hashes, P1 checkpoint hash, pretrained model hash and hyperparameters. History includes supervised and unlabeled losses, MC variance, calibration magnitude, retained fraction, unlabeled head-gradient norm, runtime, and peak GPU memory. Comparison reads completed summaries only.
